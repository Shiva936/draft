# Software security policy

Weighted risk conditions for security-sensitive software changes.

Separate from `draft.software.project` on purpose: a project may want the
software view rules without this policy's opinions, or this policy without those
view rules. Bundling them would force one decision to carry the other.

Draft evaluates these rules and attaches no meaning to what they match. What
counts as an authentication surface is this package's claim, and a project that
disagrees can replace it.
